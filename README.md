# TripMate
TripMate is an interactive travel planning website designed to help users create personalized itineraries with ease. Users can search for places using an integrated Google Maps interface, add locations to their itinerary, and view detailed travel times between destinations. The website includes the following features:

<ul>
    <b>Place Search & Auto-Complete:</b> Search for locations using Google Places, with auto-completion for a smooth user experience.

    <b>Drag-and-Drop Itinerary:</b> Users can easily reorder destinations in their itinerary by dragging and dropping items, with travel times dynamically updated.

    <b>Travel Time & Distance Calculation:</b> Automatically calculates and displays the driving distance and estimated travel time between consecutive destinations.

    <b>PDF Export:</b> Export your itinerary, including travel times and distances, as a PDF for easy reference.

    <b>Dark Mode:</b> Toggle between light and dark mode for an enhanced user experience, especially in low-light conditions.
</ul>


TripMate is perfect for anyone looking to organize and plan their travels efficiently, with real-time travel data and easy itinerary management.
